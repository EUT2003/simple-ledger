# Simple Ledger

[中文](README.md) | [English](README_EN.md)

A lightweight Android-only bookkeeping app built with Kotlin and Jetpack Compose.

## Features

- Income, expenses, and transfers between accounts
- Preset categories for income and expenses
- Account management: create, edit, and delete accounts
- Create, edit, delete, and search transactions
- Date picker and built-in calculator for four basic operations
- CNY, USD, EUR, GBP, JPY, HKD, and TWD support
- Home and account views for balances, monthly income, and monthly expenses
- Statistics: category donut charts and income/expense trends for 6 months, 12 months, or all time
- Light, dark, and system themes, plus seven accent colors
- Chinese and English interfaces
- Local storage for transactions, accounts, and settings

## Requirements

- Android Studio
- JDK 17
- Android SDK 35

## Run the project

1. Open this project folder in Android Studio.
2. Wait for Gradle sync to finish.
3. Connect an Android device or start an emulator.
4. Run the app.

## Download

Packaged Android APK files are available from this repository's **Releases** page.

## Data

Transactions, accounts, and settings are stored only on the device. Using **Clear all data** in Settings deletes local transactions and custom accounts, then restores the default settings.
