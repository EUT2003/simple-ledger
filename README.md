# 轻记账 / Simple Ledger

[中文](README.md) | [English](README_EN.md)

一个仅面向 Android 的简易记账应用，使用 Kotlin 与 Jetpack Compose 开发。

## 功能

- 收入、支出与账户间转账
- 收入和支出的预设分类
- 多账户管理：新增、修改、删除账户
- 账单的新增、修改、删除与搜索
- 日期选择与内置四则运算计算器
- 支持 CNY、USD、EUR、GBP、JPY、HKD、TWD
- 主页与账户页的余额、当月收入、当月支出
- 统计页面：分类圆环图、收入支出趋势图、6 个月／12 个月／全部时间切换
- 亮色、暗色、跟随系统主题，以及 7 种主题颜色
- 中文和英文界面
- 本地保存账单、账户与设置

## 运行要求

- Android Studio
- JDK 17
- Android SDK 35

## 运行项目

1. 用 Android Studio 打开本项目文件夹。
2. 等待 Gradle 同步完成。
3. 连接 Android 设备或启动模拟器。
4. 点击运行按钮。

## 下载

已打包的 Android APK 会随版本发布在本仓库的 **Releases** 页面，可直接下载后安装。

## 数据说明

账单、账户和应用设置仅保存在设备本地。使用设置中的“清空所有数据”会删除本地账单与自建账户，并恢复默认设置。
